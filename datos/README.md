# Datos del desafío

Productor: Servicio de Impuestos Internos de Chile (SII). Extracción declarada: octubre de 2025. Años comerciales: 2005–2024. Los originales contienen hojas Datos y Notas; conservarlas al trabajar sobre copias.

- PUB_TRINT.xlsb: agregado nacional por 18 tramos de ventas.
- PUB_TRINT_RUBR.xlsb: tramo y rubro económico. Para la extensión comenzar por 2018–2024.

Fuente: https://www.sii.cl/sobre_el_sii/estadisticas_de_empresas.html

Enlaces originales: https://www.sii.cl/sobre_el_sii/empresas/PUB_TRINT.xlsb y https://www.sii.cl/sobre_el_sii/empresas/PUB_TRINT_RUBR.xlsb

Las filas agrupan empresas. Las ventas son estimaciones tributarias en UF. Leer las notas para interpretar ventas no estimables, reserva estadística y convenciones de medición. La inclusión no atribuye a estos datos una licencia del curso.

manifest.json registra tamaños y SHA-256 de los dos datos y de la presentación. La versión en la web puede cambiar; estas copias fijan la referencia del desafío.
