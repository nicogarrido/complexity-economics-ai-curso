# Explicación y modelización económica con inteligencia artificial

Sitio del curso para estudiantes: https://nicogarrido.github.io/complexity-economics-ai-curso/

Allí están las actividades de cada clase, los formularios para responder, el simulador, las consignas para IA y los datos del SII. Este repositorio contiene los mismos archivos:

- `index.html`: página principal del sitio.
- `datos/`: extracto 2024 (`Datos_SII_2024.csv`), originales del SII y procedencia.
- `actividades/`: cuaderno con las fichas, consignas para IA y actividad de código.
- `simulador/`: simulador (funciona en el navegador) y especificación del modelo.
- `presentaciones/`: diapositivas de las dos clases.
- `codigo/`: motor del modelo y pruebas, opcional.
