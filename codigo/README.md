# Código opcional

No se necesita para las clases. `modelo.cjs` contiene el mismo motor incorporado en `simulador/Simulador.html`. Con Node.js instalado, ejecutar `node test-modelo.cjs` desde esta carpeta comprueba conservación, capacidad, fidelidad y reproducción en 108 configuraciones. No requiere paquetes externos.

Si modificas el motor, documenta qué cambiaste y por qué, y conserva el original. Si se usa IA, identifica las tareas delegadas y las verificaciones propias.
